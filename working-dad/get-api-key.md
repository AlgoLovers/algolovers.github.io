# 🔑 Gemini API 키 발급 가이드 (무료 · 1분)

WorkingDad가 학교 문서를 자동으로 읽어 일정을 정리하려면 **무료 Gemini API 키**가
한 번 필요해요. 아래대로 따라오면 **1분**이면 끝나요.

> 💳 **신용카드·결제수단 등록이 전혀 필요 없어요.**
> 구글 계정(지메일)만 있으면 됩니다. Google AI Studio의 개발자 키는 **무료 등급**이라
> 카드를 넣지 않아도 바로 발급돼요.
>
> 🆓 **요금 걱정 안 해도 돼요.** 이 앱은 문서 1장에 1번만 호출해서, 하루에 수십 장을
> 넣어도 무료 한도(하루 1,500건)의 몇 %밖에 안 써요. 무료 범위 안에서는 **요금 0원**.

---

## 📱 순서 (5단계)

### 1) 발급 페이지 열기
앱의 **[키 발급받으러 가기]** 버튼을 누르면 아래 페이지가 바로 열려요.
직접 열려면 브라우저에서: **https://aistudio.google.com/apikey**

### 2) 구글 계정으로 로그인
평소 쓰는 **지메일 계정**으로 로그인하면 돼요. (새 계정 안 만들어도 됨)
- 이때도 카드 정보는 묻지 않아요.

### 3) "API 키 만들기(Create API key)" 클릭
페이지 오른쪽 위(또는 가운데)의 **`+ Create API key`** 버튼을 눌러요.

### 4) 프로젝트 선택 → 키 생성
- **"Create API key in new project"**(새 프로젝트에서 만들기)를 고르면 제일 간단해요.
- 잠깐 기다리면 `AIza...` 로 시작하는 **키 문자열**이 만들어져요.

### 5) 키 복사 → 앱에 붙여넣기
- 만들어진 키 옆의 **복사** 아이콘을 눌러 복사해요.
- WorkingDad 앱 → **설정 → API 키** → 붙여넣기 → 저장. 끝!

**https://ai.google.dev/gemini-api/docs/api-key**

## ✅ 안심 포인트 다시 정리
- **카드 등록 불필요** — 무료 등급이라 결제수단 없이 발급돼요.
- **요금 0원** — 이 앱 사용량은 무료 한도로 충분해요. (앱의 *설정 → API 사용량*에서
  오늘 몇 건 썼는지, 무료 한도 대비 얼마인지 확인돼요.)
- **키는 이 폰에만 저장** — 우리 서버로 보내지 않아요.

## 🔒 키 관리 팁
- API 키는 **비밀번호처럼** 다뤄요. 남에게 공유하거나 채팅에 그대로 붙여넣지 마세요.
- 같은 키를 **여러 앱·기기**에 쓰면 무료 한도가 **합산**돼요. 용도별로 키를 따로
  발급하면 한도가 분리돼서 안전해요.
- 실제 전체 사용량은 앱의 *설정 → API 사용량 → [구글에서 실제 사용량 확인]* 버튼으로
  구글 콘솔에서 볼 수 있어요.
